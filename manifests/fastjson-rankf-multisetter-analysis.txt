Fastjson RankF multi-state-setter analysis
===========================================

Purpose
-------
Investigate whether the two large RankF BSS outliers for Fastjson can be
explained by each brittle test having multiple valid state-setters, and whether
the reported rank appears to correspond to a single arbitrary setter or the
best-ranked valid setter.

RankF candidate-ranking output CSVs.

RankF outcome-generation semantics
----------------------------------
The BSS implementation stores all state-setters for each brittle in a set and
getPassOrFail() iterates over that set. An execution is modeled as PASS when
any recorded state-setter occurs before the brittle test.

Therefore RankF's BSS outcome-generation model recognizes multiple alternative
state-setters for these Fastjson brittles.

Interpretation
--------------
The Fastjson RankF outliers cannot be explained merely by evaluating one
poorly ranked state-setter while other valid alternatives rank highly.

When the candidate output is joined against every state-setter recorded in
RankF's BSS ground truth, the best valid state-setter is rank 119 for test_7
and rank 109 for test_8. These reproduce the previously observed outlier ranks.

Thus, for these two artifact cases, none of the 165/163 recorded valid
state-setters appears in the Top 100.

This analysis does NOT establish from a separate downstream evaluation script
that RankF explicitly computes min(rank) over all valid state-setters. Such a
downstream evaluator was not located in the inspected artifact. Instead, the
best rank was independently recomputed over all recorded valid setters and
happens to reproduce the observed 119 and 109 values exactly.

Possible mechanism to investigate
---------------------------------
Because any one of many alternative state-setters can make the synthesized
BSS execution pass, unrelated tests that co-occur before the brittle in PASS
orders may also accumulate positive RankF evidence. With 163-165 alternative
setters, evidence may be distributed across many true setters while some
non-setters accumulate stronger scores.

This is currently a plausible explanation, not a manually validated causal
result.

Terminology note
----------------
"Valid state-setter" in this note means a state-setter recorded as positive
BSS ground truth in RankF's artifact. The 165/163 pairs have not been
individually manually revalidated in the Fastjson repository during this
analysis.
